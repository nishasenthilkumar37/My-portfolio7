# Nisha S — Personal Portfolio Website

A personal portfolio website for **Nisha S** (Web Designer & Front-End Developer).

## 🌷 Technology Stack
- **Pure HTML5** (Semantic & Accessible)
- **Modern CSS3** (Floral color system: Cream `#F7F0E6`, Burgundy `#6B1F32`, Dusky Pink `#B9828F`)
- **Vanilla JavaScript (ES6+)** (No build tools or frameworks required)
- **HTML5 Canvas & Web Audio API** (Interactive physics and synthesizers)

## ✨ Key Features & Sections
- **Opening Curtain Experience**: Elegant diagonal entrance of realistic photographic burgundy tulip with "Click here" interaction.
- **Hero Page with 3D Parallax Tulip**: High-definition realistic tulip background exclusively on the home screen with smooth 3D mouse parallax and floating dynamics.
- **About Me**: Visual persona, narrative, 4 core competency highlights, and interactive Design Philosophy tabs.
- **What I Can Do / Services**: 6 interactive 3D tilt cards with deliverables.
- **Skills Matrix**: Categorized filterable technical matrix (Frontend, Databases, Tools).
- **Featured Projects**:
  - **VOLTA & CO. — Vintage Bulbs**: Full-stack lighting atelier with an embedded live **Bulb Studio Simulator** (real-time canvas filament glow, warmth, tint, and filament spirals).
  - **DRAWCRAFT — Drawing Mastery Studio**: Art education platform with an embedded live **Drawing Canvas Studio** (pencil, brush, eraser, color palette, stroke sizing, undo, and PNG download).
  - **Painting Sales Marketplace**: Artisan gallery storefront showcase.
  - **Talking Dictionary & Audio Thesaurus**: Accessibility tool with live Web Speech synthesis voice demo.
- **Education Timeline**: BSc Information Technology (Emerald Heights College, 7.8 CGPA) and MBA System Management (Pursuing).
- **Resume Hub**: Interactive document preview and direct PDF download for `assets/Nisha_Resume.pdf`.
- **Contact & Connect**: Direct email with one-click clipboard copy, validated contact form, and floral confetti celebration.
- **UI Enhancements**: Custom cursor, scroll progress bar, audio synthesizer toggle, and responsive mobile drawer menu.

## 🚀 Running Locally
Simply double-click `index.html` to open it in any web browser. No `npm install`, Node.js, or build step is required!
