# Project Instructions: Nisha S Portfolio

## Technology Standards
- **Stack**: Pure HTML5, Modern CSS3, Vanilla JavaScript (ES6+).
- **Prohibited**: React, Vite, Next.js, JSX, Babel, webpack, npm dependencies, or any frontend build tools/frameworks.
- **Runtime**: Must run directly in any web browser by opening `index.html`.

## Code Guidelines
- Keep all HTML in `index.html`.
- Keep all styles in `css/style.css`.
- Keep all interactive logic in `js/app.js`.
- Keep all media assets in `assets/`.
- Maintain the floral color scheme (Cream `#F7F0E6`, Burgundy `#6B1F32`, Dusky Pink `#B9828F`).
- Keep the prominent realistic tulip background exclusively on the `#home` Hero section.
